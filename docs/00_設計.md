# 訴訟費用額計算機（Web 版）設計

2026-11-22 作成。

## 1. 目的と前提

- 参照実装（PowerShell）と同じ計算・同じ出力（処分書＋費用計算書）を、ブラウザだけで動く Web アプリにする。
- まず**非公開リポジトリ**で試運転し、よければ公開する（GitHub Pages）。
- 公開時に最も重要なこと（ユーザー指定）
  1. **Excel はメールではなく、ブラウザの中で作って直接ダウンロードする。**
  2. **入力した情報をサーバー側に一切残さない。**
- **使う人は書記官に限らない**（2026-11-22 ユーザー）。STEP 1 で「裁判所書記官／申立人・代理人」を選ぶ。
  - 計算は同じ。申立人のときは頭書きの欄を申立書の欄（宛先の裁判所・部・申立人の表示・申立日）に替え、相手方の費用の取扱い（規則25条）は出さない。
  - 出力（STEP 10）: 書記官＝処分書＋計算書。申立人＝**訴訟費用額確定処分申立書＋費用計算書**（あわせて処分の見込み〔主文案・計算書〕も作れる）。
  - 退避 JSON の `header` に Web 版だけの `role`（`applicant`）・`signer`（申立書の記名）を足す。
- **処分書・申立書は Word（.docx）で出す**（2026-11-24 ユーザー）。Excel は計算書・内訳・データの 3 シート（処分書シートは外す）。
  Word も JSZip で最小限の部品（document・styles・settings）から組み立てる。体裁は A4 縦・ＭＳ 明朝 12pt・余白 上35 下27 左30 右20mm・26 行。
- 書記官実務研究報告書『民事訴訟等の費用に関する書記官事務の研究』（書実研15号）は公刊物なので、資料名・頁を画面・説明に載せてよい（2026-11-22 ユーザー）。

## 2. 作り（法人の代表者判定 houjin-daihyosha と同じ考え方）

| 部分 | やり方 |
|---|---|
| 画面 | `site/` の HTML・CSS・JavaScript だけ（ビルド不要）。10 の STEP で入力する |
| 計算エンジン | 参照実装 `engine/*.ps1`（PowerShell）を JavaScript に移す（`site/js/engine/`） |
| マスタ | メンテ用の CSV（`data/masters/`）と処理用の JS（`site/js/data/masters.js`。CSV から `tools/build-masters.mjs` で作る）の 2 本立て。直すのは CSV だけで、ずれはテスト（`tests/masters.mjs`）で見つける（2026-11-26 ユーザー）。版の日付を画面に出す |
| Excel | ひな形 `訴訟費用額確定処分_テンプレート.xlsx` を `site/js/template.js` に埋め込み、ブラウザの中で 4 つの表（tblHeader・tblDecree・tblSheet2・tblBreak）に行を書き込んでダウンロードさせる。JSZip（MIT）を `site/vendor/` に置く |
| 中断・再開 | JSON。控えはファイルとしてダウンロード、再開はファイルを選ぶか貼り付け。STEP 1・10 に、サーバー側で保存・取得しないことと JSON の保存・復元のしかた・取扱いの注意の解説を置く（2026-11-25 ユーザー。`help.js` の `DATA_NOTE`） |
| 公開 | GitHub Pages（`main` に push すると Actions が検査して公開。公開は試運転の後。URL は https://ordinarylawyer.github.io/sohikaku/ ） |

### 2.1 入力を外に出さないための約束

- サーバーで動くものは無い。計算・Excel 作成はすべてブラウザの中。
- `index.html` の CSP（`<meta http-equiv="Content-Security-Policy">`）で `connect-src 'none'`・`default-src 'self'`・`form-action 'none'` などとし、ブラウザが外部と通信できないようにする。
- 外部の CDN・フォント・アクセス解析は使わない（ライブラリも自前で置く）。
- `localStorage`・`sessionStorage`・`IndexedDB`・Cookie を使わない（閉じれば消える）。
- テストで「通信を試みる API を呼んでいないこと」「外部 URL を読んでいないこと」を検査する。

### 2.2 試運転（2026-11-22 ユーザー決定）

- 非公開リポジトリの Pages は有料で、しかも URL を知れば誰でも開けるため使わない。
- `site/index.html` を**ダブルクリックで開いても動く**ようにする（`file://`。JSON・ひな形を `fetch` で読まず、JS に埋め込む）。リポジトリを ZIP でダウンロードして試す。

## 3. 正しさの確かめ方

| 検査 | 中身 |
|---|---|
| 参照実装のテスト | 参照実装のテストの事例と期待値（主文の文言を含む）を JS のテストに移す |
| アプリのテスト | 画面の状態と退避 JSON の往復などを確かめる |
| 見本の事件 | 考案事例 事件A〜E の退避 JSON を読み込み、参照実装の期待値（主文の額）と一致すること |
| Excel | 同じ事件で、表の中身（4 つの表の行）が期待どおりであること |
| 外部通信なし | 上の 2.1 |

テストは Node.js（追加のパッケージなし）で `node tests/run.mjs`。
